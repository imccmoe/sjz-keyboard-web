fix(theme): 按用户要求彻底移除按钮悬停变色，并修复静态资源缓存

用户二次反馈「还是白的」，并建议去掉悬停效果。排查确认：
服务器返回的 CSS 已是修复版（含 .button.primary:hover 且底色为紫色），
说明浏览器命中了磁盘弱缓存 —— dev.mjs 原先没发 ETag/Last-Modified，
仅有 Cache-Control: no-cache 时浏览器缺少验证依据，仍可能沿用旧文件。

按用户要求，不再与悬停效果周旋，直接移除：

- 删除 .button:hover:not(:disabled) 的背景/边框变化
- 删除 .button.primary:hover 与 :active
- 主按钮文字色仍用 --on-accent。
  中途曾试过 color: inherit，实测会继承父元素的 --button-ink（深色），
  亮色下变成深字紫底、对比度只有 3.46，比原问题更差，已改回并加测试固定

缓存问题一并解决：
- dev.mjs 增加 ETag 与 Last-Modified，并正确处理 If-None-Match 返回 304
- 样式表引用加版本号（./styles.css?v=2），改动后加一即可强制拉取
- tests/contrast.test.js 增加断言：dev.mjs 必须提供 ETag/Last-Modified 与 304 处理

测试相应调整：原「主按钮悬停态必须重声明底色」改为
「主按钮不参与悬停变色」+「主按钮文字色不得用 inherit」，
并先剥离 CSS 注释再解析，避免注释里的 .button:hover 被误判为规则。

验证：npm test 27 通过；ui:hover 0 项不足；ui:contrast 0 项不达标
